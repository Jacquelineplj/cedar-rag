# Individual reflection - write this yourself

The handout explicitly says: "Do not ask Codex to write your personal explanation."

Add your name and, in no more than 150 words, explain:
- The path from a question to a cited answer.
- One failure or limitation you observed in the actual runs.
- One change you would test next.

If working in a pair, each partner writes a separate reflection. Record both names in README.md.
